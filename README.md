# Transaction AML Workbranch

The AML analysis, descriptive workbook generator, Ryno comparison, project
guidance, and reproducible test fixtures are in
[IBM Transactions for Anti Money Laundering (AML)](<./IBM Transactions for Anti Money Laundering (AML)/README.md>).

The full source datasets, staged Parquet populations, and the complete
five-million-row workbook remain in local/approved data storage and are
intentionally excluded from ordinary Git history. See the project guide for
setup, data placement, and workbook-generation instructions.
